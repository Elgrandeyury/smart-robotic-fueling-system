# Hardware

This folder will document the **real hardware used in the project**.

Planned contents:

- verified bill of materials
- controller / microcontroller details
- RFID hardware
- sensors
- actuators
- pump / flow-control interfaces
- power requirements
- wiring diagrams
- safety-related hardware
- prototype photos

No specific component should be treated as part of the implemented system until it is documented here with evidence from the actual build.
